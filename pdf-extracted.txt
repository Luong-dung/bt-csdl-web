Thuật toán 1 · Odd-Even Sort
Bubble sort, tách thành 2 pha xen kẽ
Bubble sort làm lần lượt  từng cặp, nên không chia  
việc được.
Pha chẵn:  cặp (0,1), (2,3), (4,5)…  
Pha lẻ:  cặp (1,2), (3,4)…
Các cặp trong cùng một pha không đụng nhau , nên  
nhiều nhân làm cùng lúc được.
Ví dụ với mảng 5 phần tử
Ban đầu   5 2 4 1 3
Pha chẵn   2 5 1 4 3
Pha lẻ     2 1 5 3 4
Pha chẵn   1 2 3 5 4
Pha lẻ  1 2 3 4 5

Code C + OpenMP
Chỉ cần thêm một dòng #pragma
#pragma omp parallel
for (int phase = 0; phase < n; phase++) {
#pragma omp for  // chia các cặp cho các nhân
    for (int i = phase % 2; i < n - 1; i += 2)
        if (a[i] > a[i+1]) swap(&a[i], &a[i+1]);
// hết mỗi pha: các nhân CHỜ NHAU (barrier)
}
phase % 2 = 0 → pha chẵn, = 1 → pha lẻ. Biên dịch: gcc -O2 -fopenmp

Code C + OpenMP
Mỗi nửa mảng là một task
void sort(int *a, int lo, int hi) {
  if (hi - lo < CUTOFF) {
    sort_tuan_tu(a, lo, hi); return;
  }
  int mid = (lo + hi) / 2;
#pragma omp task
  sort(a, lo, mid);
#pragma omp task
  sort(a, mid, hi);
#pragma omp taskwait
  merge(a, lo, mid, hi);
}
taskwait
Đợi cả hai nửa xong rồi mới trộn được.
CUTOFF = 10.000
Đoạn nhỏ thì một nhân tự làm, không  
chia tiếp. Tránh lỗi của Odd-Even!
