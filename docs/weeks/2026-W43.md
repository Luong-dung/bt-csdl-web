## 4. Tiêu chí nghiệm thu

- MANAGER thêm người chưa thuộc đội, đổi vị trí và kết thúc membership được trên web; thành viên có thể tự rời đội khi nghiệp vụ cho phép.
- User ngoài đội không có quyền quản lý; API vẫn trả 403 nếu cố gọi trực tiếp. UI xử lý 401/403 rõ ràng.
- Chặn membership ACTIVE thứ hai và thao tác làm đội mất MANAGER cuối cùng; hiển thị lỗi, giữ dữ liệu form phù hợp.
- Lịch sử membership hiển thị ENDED và ngày rời, không làm mất dữ liệu cũ.
- ADMIN thao tác CRUD catalog trên web; user thường không có nút ghi. Lỗi trùng, quan hệ đang được dùng và vòng lặp khu vực hiển thị đúng.
- API giải đấu từ chối khóa ngoại/ngày/thể thức sai bằng 4xx; quyền sửa và bảng chuyển trạng thái được tài liệu hóa và có test.
- Tạo/cập nhật/chuyển trạng thái giải có audit actor/action/resource; transaction thất bại rollback cả nghiệp vụ và audit.
- Bộ test Playwright dùng môi trường test riêng, chạy lại được; không phụ thuộc tài khoản test tạo thủ công trên database cá nhân.
